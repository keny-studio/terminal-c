| $${\color{red}Prisma}$$ |  |
|--------|---------|
| | |
| COMMAND   | ACTION |
| | |
| npm install prisma --save-dev | install Prisma CLI |
| npx prisma init	| initialize Prisma |
| npx prisma migrate dev --name MIGRATION-NAME |	create and apply a migration |
| npx prisma migrate deploy | apply pending migrations
| npx prisma migrate reset |	reset the database |
| npx prisma generate	| generate Prisma Client |
| npx prisma db seed | run the seed script |
| npx prisma studio |	launch Prisma Studio (GUI for database) |
